# NATIVE WINDOWS BUILD REQUIREMENTS:
# ------------------------------------------------------------------------------
# 1. C Compiler:
#    - MinGW-w64 GCC (recommended via MSYS2 UCRT64) OR Clang / w64devkit
#      MSYS2 package: mingw-w64-ucrt-x86_64-gcc
# 2. SQLite3 Development Library:
#    - sqlite3.h and libsqlite3.a / sqlite3.dll
#      MSYS2 package: mingw-w64-ucrt-x86_64-sqlite3
# 3. Windows Sockets & Threads:
#    - ws2_32 (standard Windows networking library, included in Windows SDK)
#    - winpthreads (POSIX threads for Windows, bundled with MinGW-w64)
# 4. Build Utilities (Optional):
#    - GNU Make: mingw-w64-ucrt-x86_64-make (or use 'build_windows.bat')
#
# QUICK COMMAND (MSYS2 UCRT64):
#   pacman -S --needed mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-sqlite3 mingw-w64-ucrt-x86_64-make
#
